### 2.1 Paragraph: INSERT-CUSTOMER

#### 2.1.1 Insert customer with caller-supplied customer number

**Description:** When the number control switch is ON, a new customer record is created using an explicitly supplied customer number together with the customer's personal, address and contact details.

**Core decision logic:**
- If the number control switch is 'ON', the customer is created with the caller-supplied customer number

**Code:**
```cobol
           IF LGAC-NCS = 'ON'
             EXEC SQL
               INSERT INTO CUSTOMER
                         ( CUSTOMERNUMBER,
                           FIRSTNAME,
                           LASTNAME,
                           DATEOFBIRTH,
                           HOUSENAME,
                           HOUSENUMBER,
                           POSTCODE,
                           PHONEMOBILE,
                           PHONEHOME,
                           EMAILADDRESS )
                  VALUES ( :DB2-CUSTOMERNUM-INT,
                           :CA-FIRST-NAME,
                           :CA-LAST-NAME,
                           :CA-DOB,
                           :CA-HOUSE-NAME,
                           :CA-HOUSE-NUM,
                           :CA-POSTCODE,
                           :CA-PHONE-MOBILE,
                           :CA-PHONE-HOME,
                           :CA-EMAIL-ADDRESS )
             END-EXEC
```

**Variables:**

| Variable name | Role | Purpose |
|---|---|---|
| `LGAC-NCS` | input | Switch that selects whether the customer number is supplied explicitly. |
| `DB2-CUSTOMERNUM-INT` | input | Supplies the customer number value inserted into CUSTOMERNUMBER. |
| `CA-FIRST-NAME` | input | Customer first name inserted into the customer row. |
| `CA-LAST-NAME` | input | Customer last name inserted into the customer row. |
| `CA-DOB` | input | Customer date of birth inserted into the customer row. |
| `CA-HOUSE-NAME` | input | House name inserted as part of the address. |
| `CA-HOUSE-NUM` | input | House number inserted as part of the address. |
| `CA-POSTCODE` | input | Postcode inserted as part of the address. |
| `CA-PHONE-MOBILE` | input | Mobile phone number inserted into the customer row. |
| `CA-PHONE-HOME` | input | Home phone number inserted into the customer row. |
| `CA-EMAIL-ADDRESS` | input | Email address inserted into the customer row. |

**Description:** When the number control switch is not ON, a new customer record is created and the database generates the customer number automatically.
